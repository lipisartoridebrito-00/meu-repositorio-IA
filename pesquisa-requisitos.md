# Pesquisa: Requisitos Funcionais e Não Funcionais

## O que são Requisitos Funcionais?

Requisitos Funcionais são as funções e ações que um sistema deve realizar para atender às necessidades dos usuários. Eles descrevem o que o sistema deve fazer.

### Exemplos em um aplicativo como o iFood:

1. O usuário deve conseguir pesquisar restaurantes e pratos.
2. O usuário deve conseguir adicionar produtos ao carrinho e realizar um pedido.
3. O aplicativo deve permitir acompanhar o status da entrega.

## O que são Requisitos Não Funcionais?

Requisitos Não Funcionais definem características de qualidade, desempenho, segurança e funcionamento do sistema. Eles descrevem como o sistema deve funcionar.

### Exemplos em um aplicativo como o iFood:

1. O aplicativo deve carregar as páginas principais em poucos segundos.
2. Os dados dos usuários e pagamentos devem ser protegidos por mecanismos de segurança.
3. O sistema deve conseguir atender muitos usuários ao mesmo tempo sem apresentar grandes problemas de desempenho.

## Diferença entre eles

A principal diferença é que os Requisitos Funcionais descrevem **o que o sistema faz**, enquanto os Requisitos Não Funcionais descrevem **como o sistema deve funcionar**.

Por exemplo, em um aplicativo de delivery:

- **Funcional:** permitir que o usuário faça um pedido.
- **Não funcional:** o pedido deve ser processado de forma rápida e segura.

## Conclusão

Os dois tipos de requisitos são importantes para o desenvolvimento de um software. Os requisitos funcionais garantem que o sistema tenha as funções necessárias para os usuários, enquanto os requisitos não funcionais ajudam a garantir qualidade, segurança, velocidade e confiabilidade.
